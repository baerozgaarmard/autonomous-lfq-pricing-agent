# Security Policy

## Vulnerability Disclosure

Security and financial calculation integrity are paramount for this repository. If you identify a potential security issue or logic vulnerability, please do not file a public issue.

Please report the finding privately through GitHub:
1. Go to the **Security** tab of this repository on GitHub.
2. Select **Report a vulnerability** to submit a confidential report.

If this route is not accessible, you may reach out directly to the maintainer via their GitHub profile (@baerozgaarmard).

## Operational Safety Boundary

This application operates as a decision-support advisory system. It does not publish, execute, or push prices to external production systems.
